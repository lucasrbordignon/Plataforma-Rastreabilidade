# Glossário

- **Lote**: conjunto de itens produzidos ou recebidos juntos, com identificação única.
- **OP (ordem de produção)**: pedido para produzir uma quantidade de um produto.
- **Genealogia**: árvore/grafo de quais lotes deram origem a quais. Ver [[Modelo de Grafo]].
- **Rastreio (trace)**: de um lote final, descobrir de onde veio (para trás).
- **Recall**: de um lote de matéria-prima, descobrir para onde foi (para frente). Ver [[Recall e Rastreio]].
- **PLC**: controlador lógico programável das máquinas.
- **Edge**: software que roda perto das máquinas. Ver [[Go Edge Agent]].
- **Port / Adapter**: interface do núcleo / implementação tecnológica. Ver [[Arquitetura Hexagonal]].
- **Outbox**: tabela que garante publicação atômica de eventos. Ver [[Outbox Pattern]].
- **DLQ**: dead letter queue, destino de mensagens que falharam. Ver [[Idempotencia e DLQ]].
- **OTLP**: protocolo do OpenTelemetry. Ver [[OpenTelemetry]].
- **IRSA**: IAM Roles for Service Accounts (permissões AWS por pod). Ver [[Seguranca]].
- **MSK**: Kafka gerenciado da AWS. Ver [[AWS Mapeamento]].
- **MOC**: *map of content*, nota-índice. Ver [[Home]].
